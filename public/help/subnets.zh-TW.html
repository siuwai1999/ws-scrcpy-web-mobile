子網路與 CIDR 速查表

用白話說明 ws-scrcpy-web 接受的子網路格式。

什麼是子網路?

IP 位址分成兩個部分:一部分識別網路,另一部分識別該網路上的特定主機(裝置)。子網路是一段有名稱的位址範圍,範圍內所有位址的網路部分都相同。

在家用網路中,你擁有的每台裝置 — 手機、筆電、電視、路由器 — 都在同一個子網路上。掃描子網路,就是檢查該範圍內每個可能的主機位址。

什麼是 CIDR 表示法?

CIDR(無類別域間路由)把子網路寫成位址加上斜線與數字,例如 192.168.1.0/24。斜線後的數字是前綴長度 — 32 位元中有多少位元屬於網路部分。

前綴越小,子網路越大。/24 有 256 個位址(254 個可用);/16 有 65,536 個位址。

對於 /30 及更短的前綴,「可用主機數」不含網路位址(第一個)與廣播位址(最後一個)。

私有 IP 範圍(RFC 1918)

家庭與辦公室網路使用三段保留給私用的 IP 位址範圍之一。你的路由器會選一段,並將其中的位址分配給每台裝置。

  • 10.0.0.0/8 — 16,777,216 個位址。常用於大型組織。
  • 172.16.0.0/12 — 1,048,576 個位址。較不常見。
  • 192.168.0.0/16 — 65,536 個位址。大多數家用路由器的預設值。

我的家用路由器用的是哪一段?

大多數消費型路由器(Netgear、TP-Link、Linksys、Google Wifi 等)預設使用 192.168.0.0/24 或 192.168.1.0/24。有些 ISP(包括 Xfinity 和 Verizon)使用 192.168.86.0/24 或類似的範圍。

查看你自己的子網路:

  • Windows:開啟命令提示字元,執行 ipconfig。在你的 Wi-Fi 或乙太網路介面卡下,找出「IPv4 位址」與「子網路遮罩」。
  • Mac / Linux:開啟終端機,執行 ifconfig 或 ip addr。找出顯示你的位址與 /N 前綴的 inet 那一行。

如果你的 IPv4 位址是 192.168.1.42、網路遮罩是 255.255.255.0,你就在 192.168.1.0/24 上。

如何在 ws-scrcpy-web 中輸入子網路

「新增子網路」對話框接受三種格式:

1. CIDR 表示法 — 標準寫法。範例:

192.168.1.0/24
10.0.0.0/16
192.168.86.0/24

允許的前綴範圍是 /16 到 /32。更大的範圍(/15 及以下)會被拒絕,因為一次掃描超過 65,534 台主機慢得不切實際。若需要涵蓋更多,請新增多個 /16。

2. 單一 IP — 視為 /32(一台主機)。當你確切知道某台裝置的位址時很有用:

192.168.1.5

3. IP 範圍 — 單一 /24 內的連續區段。兩種寫法:

192.168.1.10-192.168.1.50
192.168.1.10-50

兩者都表示「192.168.1.x 網路上從 .10 到 .50 的位址」— 共 41 台主機。範圍必須維持在同一個 /24 內(只有最後一個數字會變)。更大的範圍請使用 CIDR。

掃描實際上做了什麼?

對於你列出的子網路中的每台主機,ws-scrcpy-web 會同時做兩件事:

  • mDNS 探索 — 詢問區域網路中有哪些裝置廣播 ADB 服務。已啟用無線偵錯的新式 Android 裝置通常會在這裡出現。
  • TCP port 5555 探測 — 嘗試對每台主機的 port 5555 建立 TCP 連線。若成功,掃描器會執行 adb connect,確認該主機真的使用 ADB(而不只是別的東西剛好監聽該連接埠),然後乾淨地中斷連線,並將該主機加入你的可用裝置清單。

掃描是唯讀的:不會對任何裝置寫入或變更任何東西。就像檢查每個位址有沒有門鈴,但不會進門。
