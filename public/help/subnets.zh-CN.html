子网与 CIDR 速查表

用白话说明 ws-scrcpy-web 接受的子网格式。

什么是子网?

IP 地址分成两个部分:一部分识别网络,另一部分识别该网络上的特定主机(设备)。子网是一段有名称的地址范围,范围内所有地址的网络部分都相同。

在家用网络中,你拥有的每台设备 — 手机、笔记本电脑、电视、路由器 — 都在同一个子网上。扫描子网,就是检查该范围内每个可能的主机地址。

什么是 CIDR 表示法?

CIDR(无类别域间路由)把子网写成地址加上斜线与数字,例如 192.168.1.0/24。斜线后的数字是前缀长度 — 32 位中有多少位属于网络部分。

前缀越小,子网越大。/24 有 256 个地址(254 个可用);/16 有 65,536 个地址。

对于 /30 及更短的前缀,“可用主机数”不含网络地址(第一个)与广播地址(最后一个)。

私有 IP 范围(RFC 1918)

家庭与办公室网络使用三段保留给私用的 IP 地址范围之一。你的路由器会选一段,并将其中的地址分配给每台设备。

  • 10.0.0.0/8 — 16,777,216 个地址。常用于大型组织。
  • 172.16.0.0/12 — 1,048,576 个地址。较不常见。
  • 192.168.0.0/16 — 65,536 个地址。大多数家用路由器的默认值。

我的家用路由器用的是哪一段?

大多数消费型路由器(Netgear、TP-Link、Linksys、Google Wifi 等)默认使用 192.168.0.0/24 或 192.168.1.0/24。有些 ISP(包括 Xfinity 和 Verizon)使用 192.168.86.0/24 或类似的范围。

查看你自己的子网:

  • Windows:打开命令提示符,运行 ipconfig。在你的 Wi-Fi 或乙太网络适配器下,找出“IPv4 地址”与“子网掩码”。
  • Mac / Linux:打开终端,运行 ifconfig 或 ip addr。找出显示你的地址与 /N 前缀的 inet 那一行。

如果你的 IPv4 地址是 192.168.1.42、网络掩码是 255.255.255.0,你就在 192.168.1.0/24 上。

如何在 ws-scrcpy-web 中输入子网

“添加子网”对话框接受三种格式:

1. CIDR 表示法 — 标準写法。范例:

192.168.1.0/24
10.0.0.0/16
192.168.86.0/24

允许的前缀范围是 /16 到 /32。更大的范围(/15 及以下)会被拒绝,因为一次扫描超过 65,534 台主机慢得不切实际。若需要涵盖更多,请添加多个 /16。

2. 单一 IP — 视为 /32(一台主机)。当你确切知道某台设备的地址时很有用:

192.168.1.5

3. IP 范围 — 单一 /24 内的连续区段。两种写法:

192.168.1.10-192.168.1.50
192.168.1.10-50

两者都表示“192.168.1.x 网络上从 .10 到 .50 的地址”— 共 41 台主机。范围必须维持在同一个 /24 内(只有最后一个数字会变)。更大的范围请使用 CIDR。

扫描实际上做了什么?

对于你列出的子网中的每台主机,ws-scrcpy-web 会同时做两件事:

  • mDNS 探索 — 询问局域网中有哪些设备广播 ADB 服务。已启用无线侦错的新式 Android 设备通常会在这里出现。
  • TCP port 5555 探测 — 尝试对每台主机的 port 5555 建立 TCP 连接。若成功,扫描器会运行 adb connect,确认该主机真的使用 ADB(而不只是别的东西刚好监听该端口),然后干净地断开连接,并将该主机加入你的可用设备清单。

扫描是唯读的:不会对任何设备写入或更改任何东西。就像检查每个地址有没有门铃,但不会进门。
